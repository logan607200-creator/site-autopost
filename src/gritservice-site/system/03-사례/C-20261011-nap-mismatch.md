# 사례 C-20261011-nap-mismatch
날짜: 2026-10-11
패턴: nap-mismatch
출처: 이 스레드의 대화 기록(2026-10-07~11). 사장님 반려·지적 또는 Claude가 스스로 찾아낸 것.

- 상황: GEO 점검 중 연락처 칸 주소가 '교하로 1312-53'까지만 있고 '1동 1층'이 빠져 있었다. 다른 곳은 모두 '1동 1층'까지 있었다.
- 판단: 처음 만들 때 짧은 주소 상수를 연락처 칸에 썼고 아무도 대조하지 않았다.
- 결과: 연락처 칸도 상세주소로 고쳤다. 주소가 곳곳에서 다르면 검색·AI가 같은 업체로 보지 못할 수 있다.
- 교훈: 주소·전화·사업자번호는 정본 한 곳에서만 가져오고, 사이트 전체와의 대조는 검사 C1이 한다.
