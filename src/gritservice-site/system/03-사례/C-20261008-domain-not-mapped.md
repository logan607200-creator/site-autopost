# 사례 C-20261008-domain-not-mapped
날짜: 2026-10-08
패턴: domain-not-mapped
출처: 이 스레드의 대화 기록(2026-10-07~11). 사장님 반려·지적 또는 Claude가 스스로 찾아낸 것.

- 상황: gritservice.co.kr이 아이비 서버로 오기 시작했지만 gritservice 폴더에 연결되지 않아 메인페이지가 안 보였다.
- 판단: 파일이 사라졌다는 사장님 말씀을 처음엔 파일 문제로 보고 파일을 다시 올리게 안내했다.
- 결과: 파일은 무사했다(zip 확인). 원인은 도메인과 폴더 연결 쪽일 가능성이 높다. 아이비 고객센터 확인이 필요하다(미확정).
- 교훈: '사라졌다'는 말을 받으면 파일 보존부터 확인하고, 그다음 도메인·폴더 연결을 본다. 코드로 막을 수 없는 사람 판단 영역이다.
