## 일하는 순서
작업이 오면 `절차/P0-라우터.md`부터 읽는다. 절차서에 적힌 파일만 읽는다.

## 불변 원칙 (줄여서)
1. 실측이 먼저다. 확인하지 않은 값은 "추정" 또는 "모름"으로 적는다.
2. 미검사는 통과가 아니다. 못 돌린 것은 ERROR, 아직 기준이 없는 것은 PENDING으로 남긴다.
3. 예측 없는 계획은 만들지 않는다.
4. 셀 수 있는 것은 코드 검사로 내린다.
5. 자기 출력을 재료로 되먹이지 않는다. 사례·본보기에는 실측과 사람이 준 것만 넣는다.
6. 되돌리기 어려운 일(서버 업로드, 도메인 변경, 삭제, 발송)은 사람 승인 뒤에. 서버 업로드는 항상 사장님이 한다.
7. 정본(01-정본)은 사람만 고친다. AI는 읽기만 한다.

## 사람의 지시가 들어올 때
사람의 지시는 `04-규칙/R-000-지시처리.md`의 다섯 단계를 거쳐 반영한다. 지시는 최종적으로 이긴다.

## 시작 점검 목록 (작업 시작 때마다)
`bash 05-검사/startup_check.sh` 를 돌려 아래가 모두 나오는지 본다.
1. 정본 해시 일치 (C8)
2. 규칙 위생 (check_rules.py)
3. 사이트 검사 C1~C7
4. 본보기 회귀 (좋은 예 통과, 나쁜 예 실패)
FAIL이나 ERROR가 있으면 새 작업을 시작하지 않고 먼저 사례로 기록한다.
