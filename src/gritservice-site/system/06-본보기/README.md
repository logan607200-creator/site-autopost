# 본보기 (회귀 테스트)
- `good/`: 사장님이 승인한 최신 사이트의 텍스트 4개. 모든 검사를 통과해야 한다(단, C5의 google 코드 대기는 PENDING).
- `bad/<이름>/`: 과거에 났거나 날 수 있는 사고를 재현한 파일. good 위에 덮어 씌워 검사하며 `expect.txt`의 검사가 **반드시 FAIL** 이어야 한다.
- 사이트가 정당하게 바뀌면 good/ 은 사람 승인 뒤에만 갱신한다. 검사를 고쳐서 bad가 통과하게 만들지 않는다.
- C6(upload=zip=재빌드)과 C8(정본 해시), 규칙 위생은 파일이 아니라 `05-검사/regress.py`가 그때그때 망가뜨려 확인한다.
- 이 폴더에는 실측 결과와 사람이 준 것만 넣는다. Claude가 쓴 문구를 '좋은 예'로 되먹이지 않는다(good/ 은 사장님이 승인한 빌드).
