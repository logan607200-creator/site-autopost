# P2 검사·채점 (검사만 한다)
## 이름과 용도
P1이 만든 결과나 현재 `../upload`를 검사한다. 만든 쪽이 자기 것을 채점하지 않도록 만들기와 분리했다.
## 읽을 것
`05-검사/check_site.py` 의 출력, `06-본보기/README.md`
## 만들 것
`check_site.py --dir <검사할 폴더>` 출력 전문과 한 줄 판정(통과/막힘/대기). 못 돌린 검사는 ERROR, 기준이 없거나 코드를 아직 못 받은 것은 PENDING으로 그대로 적는다.
## 절차
1. `python3 05-검사/check_site.py --dir <폴더>`. 끝: C1~C8 각각의 상태가 나옴.
2. FAIL·ERROR 가 있으면 진행 중단, P1로 돌려보내거나 사람에게 보고. 재시도 상한 3회.
3. 임시 폴더 결과가 모두 PASS(또는 설명된 PENDING)이면 P3로 보낼 수 있다고 적는다.
## 하지 않는 것
파일 수정, 검사 기준 완화(기준을 느슨하게 고치면 본보기가 걸린다), 정본 수정.
