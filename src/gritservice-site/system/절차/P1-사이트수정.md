# P1 사이트 수정 (만들기만 한다)
## 이름과 용도
문구나 코드를 바꿔야 할 때. 사람의 지시이면 `04-규칙/R-000-지시처리.md`를 먼저 거친다.
## 읽을 것 (순서대로, 이번에 필요한 것만)
1. `01-정본/brand.md`, `01-정본/services.md`, `01-정본/금지.md`
2. `04-규칙/` 에서 이번 변경과 관련된 규칙
3. `../make_grit.py` 에서 바꿀 부분만
## 만들 것
임시 폴더에 빌드한 결과(`python3 ../make_grit.py <임시폴더>`). `../upload`를 직접 덮어쓰지 않는다. 사실 주장을 새로 쓰면 어느 정본 항목에 근거하는지 한 줄 적고, 정본에 없으면 사장님 확인 대기로 표시한다.
## 절차
1. 정본에서 값을 가져온다(주소·전화·서비스 이름을 손으로 다시 쓰지 않는다). 끝: 값이 정본과 같은지 눈으로 확인.
2. 수정한다. 끝: 빌드가 오류 없이 끝남.
3. P2로 넘긴다. 재시도 상한 3회(빌드 실패가 3번이면 멈추고 보고).
## 하지 않는 것
검사·채점(P2의 일), 정본 수정, `../upload`·zip 덮어쓰기와 배포(P3), 확인 안 된 서비스·실적·후기 쓰기.
