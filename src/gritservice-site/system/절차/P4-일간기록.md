# P4 일간 기록 (매일 아침 9시)
## 이름과 용도
사장님이 불러 준 숫자를 실측 CSV에 넣는다. 해석하지 않는다.
## 읽을 것
`05-검사/today.py` 출력, `01-정본/질의목록.md`
## 만들 것
`02-실측/exposure.csv`, `calls.csv`, `index_status.csv` 의 새 줄(줄 추가만).
## 절차
1. `python3 05-검사/today.py` 로 오늘 기록할 항목을 알려 준다(월요일은 전체, 그 외 3개 순환).
2. 사장님이 준 값을 `python3 05-검사/record.py ...` 로만 기록한다. 끝: 거부 메시지 없이 "기록:" 줄이 나옴.
3. 확인 못 한 칸은 ERROR로 기록한다. 빈칸이나 N으로 채우지 않는다. 0건과 못 센 것은 다르다.
4. 기록이 끝나면 오늘 기록 개수를 한 줄로 보고한다.
## 하지 않는 것
이미 쓴 줄 수정·삭제, 값 해석과 결론, 추정치를 실측처럼 기록, 자기가 만든 문장을 노출 근거로 넣기.
