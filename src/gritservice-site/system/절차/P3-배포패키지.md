# P3 배포 패키지 (사람 승인 필요)
## 이름과 용도
P2를 통과한 결과를 서버에 올릴 파일로 내보낸다. 서버 업로드는 사장님이 직접 한다(되돌리기 어려운 일).
## 읽을 것
P2의 통과 기록, `../upload`, `../gritservice-upload.zip`
## 만들 것
`../upload` 와 `../gritservice-upload.zip`(같은 내용), 올릴 파일 목록과 "올린 뒤 확인법"을 적은 안내.
## 절차
1. 사장님 승인을 받는다. 끝: 승인 문장이 스레드에 있음.
2. `../upload` 갱신, zip 재생성. 끝: `check_site.py` 의 C6(upload=zip=재빌드)이 PASS.
3. 안내에 "바뀐 파일만 /public_html/gritservice 에 덮어쓰기"와 "올린 뒤 http(s)://gritservice.co.kr 에서 Ctrl+U로 소스를 열어 소유확인 메타가 보이는지 확인"을 적는다(사례 stale-deploy).
4. `06-본보기/good/` 은 사장님이 바뀐 사이트를 승인한 뒤에만 새로 복사한다.
## 하지 않는 것
서버 업로드, 도메인·DNS 변경, 승인 없는 덮어쓰기, 정본 수정.
