# P5 사후검토 (사슬: 어긋남 -> 사례 -> 규칙)
## 이름과 용도
계획과 실측이 다르거나 사람이 반려·지적했을 때 사례로 남기고, 같은 패턴이 2회가 되면 규칙 승격을 제안한다.
## 읽을 것
어긋난 항목, `03-사례/` 의 같은 패턴 파일, `05-검사/check_rules.py` 출력
## 만들 것
`03-사례/C-YYYYMMDD-패턴이름.md` (상황/판단/결과/교훈 네 칸 + `패턴:` 한 줄)
## 절차
1. 사람이 반려·지적한 것은 원문을 그대로 사례에 인용한다(R-000 1단계).
2. 패턴 이름을 정한다. 이미 있는 이름이면 그것을 쓴다(이름이 같아야 2회로 센다).
3. `python3 05-검사/check_rules.py` 를 돌려 "승격할 차례"가 나오면 `04-규칙/` 에 규칙 초안을 쓴다. 머리에 `근거:`(사례 링크) `충돌검토:` `항목:` 필수. 사장님 승인 후 확정.
4. 셀 수 있는 규칙이면 `check_site.py`에 검사를 추가하고, 실패 산출물을 `06-본보기/bad/`에, 좋은 산출물을 `good/`에 등록해 `regress.py`가 통과하는지 본다.
## 하지 않는 것
1회짜리를 규칙으로 올리기, 정본 수정, 검사 기준을 느슨하게 고치기, Claude가 쓴 문구를 사례·본보기의 재료로 되먹이기.
