# P0 라우터
## 이름과 용도
"무엇을 할까"를 하나로 받아 알맞은 절차로 보낸다. 모든 작업은 여기서 시작한다.
## 읽을 것
`운영규칙.md`, 이 표. (그 외는 보내진 절차서가 정한다)
## 만들 것
어느 절차(P1~P5)로 가는지 한 줄. 어디에도 안 맞으면 "설계 밖"이라 말하고 되묻는다.
## 절차
1. `bash 05-검사/startup_check.sh` 를 돌린다. FAIL·ERROR 가 있으면 새 작업 전에 P5로 사례를 남긴다.
2. 요청을 분류한다.
   - 사이트 문구·코드를 바꿔 달라 -> P1 (사람의 지시이면 먼저 R-000 다섯 단계)
   - 만든 결과를 검사해 달라 -> P2
   - 서버에 올릴 파일을 달라 -> P3
   - 오늘 기록할 것 / 숫자를 받았다 -> P4
   - 사고가 났다, 반려됐다, 어긋났다 -> P5
3. 보낸 절차서에 적힌 파일만 읽고 진행한다.
## 하지 않는 것
직접 작업하지 않는다. 정본을 고치지 않는다. 승인 없이 배포하지 않는다.
