파주 판금·도색

그릿서비스는 경기도 파주시 교하에 있는 자동차 공업사입니다. 찌그러짐·긁힘·문콕을 판금으로 복원하고, 원래 색에 맞춰 조색한 뒤 부분 또는 전체 도색합니다. 파손이나 증상 사진을 카카오톡으로 보내 주시면 필요한 작업과 범위를 먼저 안내합니다.

작업 범위

  • 판금 복원: 찌그러진 면과 라인을 판금으로 다시 잡습니다.
  • 하지작업: 연마·퍼티·프라이머로 도장 바탕을 만듭니다.
  • 조색: 차량 원래 색에 맞춰 색을 만듭니다.
  • 부분·전체 도색: 손상 범위에 맞춰 도색 범위를 정합니다.

진행 순서

  1. 사진 상담: 카카오톡이나 전화(1577-0412, 24시간)로 차량 상태를 알려 주세요.
  2. 입고·진단: 평일 09:00~18:00 입고. 직접 오기 어려우면 탁송으로 입고할 수 있습니다.
  3. 견적 안내: 항목별 견적을 먼저 드리고, 동의하신 작업만 진행합니다.
  4. 작업·출고: 작업 후 점검하고 출고합니다.

판금·도색 실제 사례

그릿서비스에 입고된 차량의 실제 작업 기록입니다.

  • 싼타페 운전석 뒤휀더·범퍼 도장

    현대 싼타페 운전석 리어휀더·범퍼 도장 손상을 범퍼 별도 도장, 휀더 블렌딩으로 복원한 파주 그릿서비스 사례.

  • K5 뒤범퍼 좌측 도장 손상 복원 도색

    기아 K5 뒤범퍼 왼쪽 도장 손상을 변형 진단부터 조색·클리어 도장, 조립 검수까지 진행한 파주 그릿서비스 사례.

  • 벤츠 E300 운전석 뒤휀더 찌그러짐·뒤범퍼 판금도색

    운전석 뒤휀더가 눌리고 뒤범퍼가 찍힌 벤츠 E300을 판금·하지작업·조색 도장으로 복원한 파주 그릿서비스 사례.

판금·도색 자주 묻는 질문

판금이랑 도색 차이가 뭐야?

판금은 찌그러진 철판 모양을 원래대로 펴서 복원하는 작업이고, 도색은 복원한 면이나 긁힌 면에 페인트를 다시 칠하는 작업입니다. 그릿서비스는 두 작업을 함께 진행합니다.

판금도색 비용은 어떻게 계산돼?

파손 범위, 작업할 패널 수, 부분 도색인지 전체 도색인지에 따라 달라집니다. 그릿서비스는 차량 확인 후 항목별 견적을 먼저 드립니다.

부분도색 하면 색 차이 나지 않아?

그릿서비스는 원래 차량 색에 맞춘 조색으로 부분 도색을 진행합니다. 색상과 도장 상태에 따라 인접 패널까지 함께 작업할지 상담 때 안내합니다.

전체도색도 해?

합니다. 그릿서비스는 부분 도색과 전체 도색을 모두 진행합니다. 범위와 색상에 따라 상담 후 안내합니다.

휠하우스 녹 판금 가능해?

녹이 생긴 부위는 상태를 확인해 판금·도색으로 복원하거나 교환을 안내합니다. 그릿서비스에 사진이나 방문으로 상담하세요.

도색 후 세차는 언제부터 해도 돼?

도색 직후에는 도장면이 충분히 굳을 때까지 고압 세차나 왁스·코팅을 피하는 것이 좋습니다. 정확한 시기는 출고 때 그릿서비스에서 안내받으세요.
